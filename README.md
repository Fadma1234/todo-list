# To do list
<img width="1920"  alt="image" src="https://github.com/user-attachments/assets/b498d32c-dec6-4cb0-9f89-9310627b3a17" />




This JavaScript project implements the core client-side functionality for a simple, interactive to-do list application. The script manages user input, dynamically creates list items in the DOM, and handles task management actions entirely within the browser. Key features include adding new tasks via an input field and button, visually marking tasks as completed by toggling a "checked" CSS class when a list item is clicked, and deleting individual tasks using a appended "remove" button that uses event propagation stopping to ensure only the removal action occurs. The project demonstrates fundamental front-end development concepts such as DOM manipulation using createElement and appendChild, event handling with addEventListener, and basic input validation using the trim() method.
